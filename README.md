# Project Description
A synthesizer to play with and mess around with different **sounds** and **effects**, built with **React** & **Tone.js**
(The application is still in early development and there are still many more improvements to come)

# Main Features
- Synth Presets
- Effect Chain
- Polyphonic Mode Toggle (not all presets are compatible)
- Keyboard Support
- Octave Switching
- Volume Controls

# Roadmap
- Sequencer & Playback
- Support for smaller screen devices
- More quality of life and UI improvements
